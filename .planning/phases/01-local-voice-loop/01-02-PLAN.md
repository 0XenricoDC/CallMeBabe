**As a** developer (or the owner using a headset), **I want to** run `python main.py --tenant=demo` and hold a natural, low-latency Italian conversation with the bot — interrupting it mid-sentence, hearing a personalized greeting — **so that** the streaming pipeline, barge-in, and transport seams are locked in before later phases.

<objective>
The thinnest end-to-end working voice slice: assemble the streaming Deepgram → Claude → ElevenLabs pipeline behind the `TransportFactory` + `STTProvider` seams, make the bot speak the demo tenant's Italian greeting on connect with barge-in active, and wire `python main.py --tenant=demo` to the Pipecat runner serving the browser WebRTC UI.

After this plan a real user can open the browser page, hear the greeting, talk to the bot in Italian, and interrupt it. Latency instrumentation and error fallback are added in Plan 03.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser mic → server pipeline | Untrusted audio crosses into the process via WebRTC |
| Process → Deepgram/Anthropic/ElevenLabs | Outbound API calls carry secrets over HTTPS |
| `--tenant` arg → tenant load | Already mitigated in Plan 01 (parameterized query) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-KEY | Information Disclosure | service construction in factory/build | mitigate | API keys read only via `os.getenv("*_API_KEY")`; never logged, never passed to TTS/console; raw provider exceptions not echoed (Task 1/2) |
| T-02-COMM | Information Disclosure | provider API calls | accept | All three SDKs use HTTPS by default (RESEARCH §V9); no manual SSL config |
| T-02-VOICE | Spoofing/quality | ElevenLabs voice_id | accept | Wrong/empty voice_id yields wrong voice, not a security issue; Plan 01 Pydantic validator already rejects empty voice_id |
| T-02-LANG | Misuse | non-Italian caller | accept | Phase 1 persona asks to call back with an operator (D-09); full non-IT→transfer is Phase 3 (HAND-03), out of scope here |
</threat_model>
